# ENI Mod - Blood Strike

Auto-built mod menu for Blood Strike (NetEase).

## Features
- Smart Aimbot (humanized, anti-ban)
- ESP / Wallhack (external overlay)
- No Recoil (85% reduction with randomization)
- QSec Anti-Cheat Bypass

## Download
Go to [Releases](../../releases) and download the latest APK.

## Build
Push to `main` branch — GitHub Actions auto-builds the APK.
